# LLM UX proxy rating protocol

These are Codex-produced heuristic ratings, not human ratings and not an independent user study. The system identity key was not used to make the ratings.

Each answer was scored on relevance, source support, completeness, direct readability and appropriate abstention using a 1–5 scale. When two answers contain the same claims and citations and differ only in attribution wording, their usefulness scores are equal and preference is a tie. Wrong-topic answers score low.

This proxy can diagnose obvious failures and whether the LM-ranked phrasing is materially more useful. It does not satisfy the blinded human usefulness gate.
