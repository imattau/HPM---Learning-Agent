# LLM UX proxy rating protocol

These are Codex-produced heuristic ratings, not human ratings and not an independent user study. The system identity key was not used to make the ratings.

Each response was assessed on a 1–5 usefulness scale for relevance to the question, source support, completeness, direct readable wording, and appropriate abstention. A change limited to attribution phrasing was treated as a tie unless it made the response materially easier or harder to use. Wrong-topic answers scored low even when citation formatting was correct.

This proxy can diagnose obvious relevance or completeness failures and whether two phrasings differ materially. It does not satisfy the blinded human usefulness gate.
