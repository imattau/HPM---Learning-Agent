# LLM UX proxy rating protocol

These are Codex-produced heuristic ratings, not human ratings and not an independent user study. The system identity key was not used to make the ratings.

Each response was assessed independently on a 1–5 usefulness scale, emphasizing: (1) answers the specific question, (2) factual support from the displayed source, (3) completeness for multi-part questions, (4) direct, readable wording, and (5) appropriate abstention when the source is silent. A wrong-topic answer receives a low score even if its citation is formatted correctly. When both responses are equally useful, preference is `tie`; otherwise the more useful answer is preferred.

This proxy is useful for diagnosing obvious relevance/completeness failures and phrasing preferences. It does not satisfy or substitute for the blinded human usefulness gate.
